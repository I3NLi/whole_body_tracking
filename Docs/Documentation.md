# Git 提交信息格式
| Type         | 用途说明                        |
| ------------ | --------------------------- |
| **feat**     | 新功能（新增代码能力、接口、模块、协议支持等）     |
| **fix**      | 修复 bug、错误逻辑                 |
| **refactor** | 代码重构，不改变功能但结构变更             |
| **perf**     | 性能优化（内存、时延、RT性能、控制率等）       |
| **docs**     | 文档更新（含 README / API / 注释体系） |
| **style**    | 格式/命名/空格/不影响逻辑              |
| **test**     | 增加或更新测试代码                   |
| **build**    | 构建系统 / 编译链配置修正              |
| **ci**       | CI/CD 或自动化脚本变更              |
| **chore**    | 小杂活（与业务逻辑无关）                |
| **revert**   | 撤回某次提交                      |
