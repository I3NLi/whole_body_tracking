# 2026-02-07_Sequential Motion 训练报错与修复
现象：在切换到下一个 npz 时触发报错：
`RuntimeError: Inplace update to inference tensor outside InferenceMode is not allowed`
触发点：`motion_cmd._resample_command(env_ids)` 运行在非 `torch.inference_mode()` 环境，导致对 inference tensor 的就地更新报错。
修复：在切换 motion 时包一层 `with torch.inference_mode():`
```
with torch.inference_mode():
    motion_cmd._resample_command(env_ids)
```
